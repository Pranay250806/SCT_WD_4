# To-Do Web Application

A simple, responsive, and user-friendly To-Do Web Application developed using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Set a date for tasks
- Set a time for tasks
- View all tasks
- Filter tasks by All, Active, and Completed
- Tasks are saved using Local Storage
- Tasks remain available after refreshing or reopening the browser
- Responsive design for desktop and mobile devices
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
